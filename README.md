# Swishy



Swishy is a Rocket League bot that specializes in the Hoops game mode.

Trained with GigaLearn and ported to RocketForge.



The current version of swishy was made fairly quickly as a proof of concept in 2025.

It is in no way the most optimized version of what it could be, but it is being released due to interest in filling the gap of a hoops bot since there are no others currently available.

If there is enough interest a v2 of Swishy, development will be considered.



Swishy has no direct relation to the Rocket League Pro + content creator Squishy other than the name.
